Teste de acesso às fontes

Descobre se uma página no navegador consegue ler as APIs do Congresso. Este teste decide se o app pode ser só uma página web ou se precisa de servidor.

Importante: este teste precisa rodar a partir de um endereço https://. Se você abrir o arquivo direto do aparelho (endereço começando com file://), tudo vai falhar por outro motivo e o resultado não vale.
