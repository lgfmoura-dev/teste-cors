Teste de acesso às fontes — versão 2

Agora separando bloqueio de CORS (o servidor não deixa) de formato errado (o servidor deixa, mas mandou XML em vez de JSON).

Como ler: se aparecer “Failed to fetch”, é bloqueio de CORS de verdade — caminho fechado. Qualquer outra mensagem significa que o servidor respondeu e o navegador conseguiu ler, ou seja, CORS está liberado e o problema é só de formato, que se resolve.

Importante: precisa rodar a partir de um endereço https://, nunca file://.
